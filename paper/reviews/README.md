# Review and audit reports

Simulated peer reviews (`round*.md`) and pre-release audits (`prerelease*.md`), all written by separate AI sessions
of the same model family as the system that drafted the paper. Each report names the commit it audited.

The public git history was rewritten once on 2026-10-13 (see `paper/AI_DISCLOSURE.md`). Commit ids written in
reports before that date may no longer exist; the commits that contained the withheld Hansard speech revisions are
shown as "[pre-rewrite commit]". Commit ids cited in the paper and the analysis plan were not affected.
